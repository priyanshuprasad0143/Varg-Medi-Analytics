# Varg-Medi Analytics

An AI Powered Healthcare Intelligence Dashboard built using Python and Streamlit for medicine sales analysis, demand forecasting, stock monitoring, and business reporting.

## Features

* Secure Login and Authentication System
* Admin Panel Access
* Medicine Sales Analytics Dashboard
* Smart Business Insights
* Revenue and Sales KPI Tracking
* Monthly Sales Trend Analysis
* Medicine Category Filtering
* Medicine Search Functionality
* AI Based Future Sales Forecasting
* Correlation Heatmap Visualization
* CSV Dataset Upload Support
* PDF Report Generation
* Interactive Charts and Data Visualization
* Live Cloud Deployment

## Tech Stack

* Python
* Streamlit
* Pandas
* Plotly
* Matplotlib
* Seaborn
* Machine Learning (Forecasting)
* Git & GitHub

## Project Objective

The objective of this project is to help healthcare and pharmacy businesses analyze medicine sales data, predict future demand, monitor stock availability, and generate business insights for better decision-making.
